## Portfolio website

A static, dependency-free portfolio written in plain HTML, CSS and JavaScript. Content is in Spanish.

**Highlights**

- Responsive layout with a mobile menu
- Technology areas in tabs with slide transitions
- Project list, timeline and certifications with links
- CV preview dialog and PDF download
- Animated particle-network background, scroll reveals and custom cursor
- Respects `prefers-reduced-motion` and keyboard navigation

**Structure**

```text
.
├── index.html              # page structure and content
└── assets/
    ├── css/styles.css      # tokens, layout, components, responsive styles
    ├── js/main.js          # menu, CV dialog, tabs, animations, background
    ├── images/             # portfolio images
    └── cv/                 # downloadable CV (PDF)
```

**Run it locally**

Open `index.html` in a browser, or serve the folder (for example with the VS Code *Live Server* extension) to test the CV download.
